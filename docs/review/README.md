## 요약

1. **전처리·시점 처리는 강의 기준을 잘 지킴.** 빠진 건 기업명 표기 변형(약칭·자회사) 처리, LLM 추출의 정량 검증(무작위 표본, 모델 기억, 프롬프트 민감도).
2. **설명가능성(w6-1)이 가장 큰 빈칸이었음.** SHAP 는 A 가 했고, 제출 규칙의 예측 분해·permutation importance·그룹별 효과는 03 문서에서 채움. 남은 건 LightGBM 의 상관 피처 묶음과 faithfulness (재은 쪽).
3. **제출 규칙 설명가능성 (03 문서):** 규칙은 gap_z 에 거의 전부 기대고, ext_range_z 효과는 작고 폴드마다 다름. "출렁인 갭은 잡음"이라는 기존 설명은 데이터와 맞지 않음(출렁임이 클수록 갭 방향이 더 잘 맞음) → 발표 문구 수정 필요. 시간외 고가·저가 이상치도 발견.
4. **채민 최종본 (01 문서 4절, 02 문서 4번):** 기간(5/29)·누수 통과. 뉴스 above 는 실적 표와 94% 일치, below 는 가이던스 정보. 단 뉴스·Reddit 방향 모두 갭이 모르는 방향을 못 맞힘. 뉴스 검증 실패 중 공백 문제 63개는 10/8 채민 보정본으로 복구됨(제외 104 → 41행, 피처가 빈 종목·날짜 87 → 40). Reddit 제외가 방향 의견이 분명한 글 쪽으로 쏠린 건 그대로.
5. **발표에 바로 넣을 것:** "크기는 맞히고 방향은 못 맞힌다"는 우리 결론이 강의의 Kogan(2009)·Antweiler & Frank(2004)와 같음 → 인용 추가.
