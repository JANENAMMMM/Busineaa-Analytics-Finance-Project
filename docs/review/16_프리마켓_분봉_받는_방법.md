# 프리마켓 분봉 받는 방법

## 0. 준비

- main 최신으로 받기: `git pull origin main`

## 1. 키를 환경변수로 설정

**Windows** (PowerShell, 설정 후 터미널·에디터 재시작)

```powershell
setx APCA_API_KEY_ID "발급받은_Key_ID"
setx APCA_API_SECRET_KEY "발급받은_Secret"
```

**Mac** (터미널)

```bash
echo 'export APCA_API_KEY_ID="발급받은_Key_ID"' >> ~/.zshrc
echo 'export APCA_API_SECRET_KEY="발급받은_Secret"' >> ~/.zshrc
source ~/.zshrc
```

## 2. 받기 (용도에 따라 하나)

**① 후보 규칙용 (재은 통합·재학습):** 9:15까지 종목당 한 줄만 저장 → `artifacts/premarket/`

```bash
uv run python work/b/features/premarket_rule.py fetch --since 2024-08-13 --until 2026-05-28
```

**② 실험 재현·검사용:** 1분봉 원본 → `cache/premarket/` (15분 안팎)

```bash
uv run python work/b/review/premarket/fetch.py
uv run python work/b/features/check_premarket_rule.py
```

검사 끝에 `4폴드 평균 0.4635`가 나오면 같은 결과입니다.

## 주의

- 홀드아웃 기간(6/1~9/14)은 위 명령에 포함되지 않습니다. 최종 재학습에 필요하면 `--since 2026-05-29 --until 2026-09-11`로 따로 받으면 되는데, 그 기간 점수를 볼지는 같이 정해요.
  - 날짜는 기준일 기준입니다. dev 마지막 기준일(5/28) 다음부터 교수님 데이터 마지막 기준일(9/11, 대상일 9/14)까지입니다.
- 키가 없거나 받기에 실패해도 후보 규칙은 자동으로 B0와 똑같이 예측합니다.
