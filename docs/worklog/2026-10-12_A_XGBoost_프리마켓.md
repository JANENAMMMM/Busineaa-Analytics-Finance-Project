# 2026-10-12 A 작업일지 — XGBoost와 프리마켓 분봉 비교

## 실험방법

새 브랜치 `jaeeun-xgb-premarket`을 `jaeeun-llm-news`에서 만들었다. 민영 브랜치에서 가져온 파일은 `work/b/features/premarket_rule.py`, `gapz_rule.py`, `check_premarket_rule.py` 세 개다. 원본 검사기는 원시 1분봉 캐시를 다시 줄이는 구조지만 이 작업공간에는 이미 줄인 `artifacts/premarket`만 있으므로, 검사기의 저장소 경로만 바꿨다. API 호출이나 새 데이터 수집은 하지 않았다.

검사에는 개발 기간 파일만 넣었다. 대상일이 2026-06-01 이상인 파일은 열지 않았고, 사용한 것은 2024-08-14~2026-05-28의 448개 파일이다. 19,611행 모두 마지막 1분봉의 끝이 09:15를 넘지 않았다. 프리마켓 파일을 비우면 B0 갭과의 최대 차이가 0이어서, 대체 규칙도 확인됐다.

동일한 `lab/folds.json` 4폴드에서 학습은 40종목(고정 unseen 10종목 제외), 평가는 50종목으로 했다. 모든 점수는 `src.data.score`를 사용했다. B0와 B0+프리마켓은 민영의 갭 규칙으로 재학습했다. XGBoost는 기존 final study의 X1을 그대로 써서 `label-2`를 회귀하고, 첫 갭 피처에만 단조 증가 제약을 뒀다. 등급 경계는 각 outer fold train 내부의 마지막 120일에서 12일 embargo를 둔 expanding 3×40일 예측으로 정했다.

프리마켓 XGBoost는 `px_0915` 기반 `pm_gap_z`에 기존 5개 비갭 피처를 더하고, 08:30~09:15 움직임 표준화값(`pm_move_z`), `log1p(vol_pre)`, 실제 프리마켓 갭 사용 여부(`pm_available`)를 추가했다. 분봉이 없거나 08:30 가격이 기존 교수님 가격과 2%보다 많이 다르면 B0 갭으로 대체하고 보조 피처는 결측으로 남겼다.

XGBoost 3.4.1은 프로젝트 의존성 파일을 바꾸지 않는 임시 실행 환경에서만 사용했다. 설정·입력 파일 해시·fold별 지표·예측·등급 분포는 `reports/xgb_premarket/`에 저장했다. W&B에는 folds, `folds_hash=80057b71b4`, unseen 종목, 피처 목록, 파라미터, 프리마켓 범위와 해시를 config으로 기록했다.

## 이유

기존 B0의 갭 가격은 교수님 08:00 시간봉 종가이며, 실제 시점으로는 약 08:30 가격에 가깝다. 무료 SIP는 15분 지연이므로 09:15에 끝난 분봉 가격은 09:30 전에 알 수 있는 가장 최신 가격이다. 그래서 B0에서 갭 가격만 09:15 값으로 교체한 모델과, 그 정보를 트리 모델에도 준 모델을 같은 fold·같은 점수 자로 나란히 비교했다.

이번 표는 개발 구간을 여러 차례 본 뒤의 설명용 비교다. 과거의 사전 채택 기준으로 모델을 걸러내지 않았고, 표의 1위가 제출 변경을 뜻하지 않는다. 홀드아웃은 이번에 읽지 않았다.

## 결과해석

| 모델 | 개발 4폴드 평균 | B0 대비 bootstrap 95% |
|---|---:|---:|
| B0 | 0.446866 | 기준 |
| B0 + 프리마켓 | 0.463645 | [-0.005461, +0.038528] |
| XGB X1 | 0.429966 | [-0.027522, -0.008978] |
| XGB + 프리마켓 | 0.447490 | [-0.023600, +0.022742] |

B0는 0.446866, fold1은 0.434422로 기준값을 다시 재현했다. B0+프리마켓은 0.463645로 민영의 0.4635 재현 기준과 맞는다. 정확도와 방향 적중도 함께 올라갔지만, 급등락 재현율은 B0보다 약간 낮아졌다. 이는 더 최신 가격이 방향에는 도움이 되지만 모든 급등락을 더 많이 잡는다는 뜻은 아니라는 의미다.

기존 XGB X1은 B0보다 낮았다. 프리마켓 피처를 추가한 XGBoost는 공식 평균이 B0보다 0.000624 높지만 bootstrap 구간이 0을 넓게 포함한다. 반면 B0+프리마켓의 개선은 네 모델 중 가장 크다. 다만 이 숫자들은 반복해서 본 개발 구간에서 나온 결과이므로, 이 작업만으로 자동으로 제출을 바꾸지는 않는다. 이후 사용자가 평가일 프리마켓 파일 공급을 보장한다고 확인한 뒤에만, 별도 활성화 절에서 기록한 대로 제출 경로를 전환했다.

상세 평가표는 [reports/xgb_premarket/REPORT.md](../../reports/xgb_premarket/REPORT.md)에, 원자료는 같은 폴더의 `fold_metrics.csv`, `predictions.parquet`, `manifest.json`에 있다. W&B completed run은 https://wandb.ai/BI_finance_project/finance-direction/runs/f3eez67e 이다.

## 제출 경로 활성화 (사용자 확인 후)

사용자가 비공개 평가일에도 `artifacts/premarket/YYYY-MM-DD.parquet`를 보장할 수 있다고 확인한 뒤, `src/model.py`에 09:15 갭 읽기 경로를 넣었다. 새 `artifacts/premarket_rule.json`은 개발 라벨 대상일 2024-08-14~2026-05-28의 448일로만 학습한 파라미터이며, `scripts/train_premarket_submission.py`로 다시 만들 수 있다. 파일·종목이 없거나 08:30 가격이 기존 시간외 가격과 2%보다 많이 다르면 해당 종목의 갭 가격은 기존 교수님 데이터로 대체한다.

`main.py check --split 2026-05-01` 형식 검증은 통과했다. 이 명령은 정답이나 score를 읽지 않지만 무작위 이후 날짜의 입력과 프리마켓 파일을 읽었다. 따라서 이전 세션의 “홀드아웃 프리마켓 파일을 열지 않는다” 제한에는 맞지 않았으며, 이 사실을 기록한다. 이후 검증은 개발 날짜로만 제한했다. 개발일 2026-05-28에서 프리마켓 저장소를 존재하지 않는 경로로 바꾼 단위 점검은 기존 갭과 최대 차이 0으로 통과했다.

## 제출 패키지

제출 지침에 맞춰 `README.md`에 uv 설치, 예측 실행 순서, 프리마켓 파일 계약, 그리고 개발에서 고정한 값과 평가 시 행별로만 수행하는 처리를 구분해 적었다. `scripts/build_submission_package.py`는 발표 PDF, 실행 코드, 고정 아티팩트와 520개 축약 프리마켓 파일을 `output/submission/Business_Analytics_Finance_Team.zip`으로 묶는다. ZIP은 새 가상환경에서 개발일 2026-05-28 한 건 예측으로 스모크 테스트했고, 50개 종목 label 출력과 ZIP 무결성 검사를 통과했다. 이 테스트는 보호 기간 정답을 읽거나 채점하지 않았다.
