## 0. 한 줄 요약

- 채민 LLM 피처(뉴스 v6, Reddit v4)를 붙인 실험 11개 + 기준 2개를 4폴드로 돌림. **채택 기준을 통과한 실험은 0개**. 제출본은 B 규칙 v1 그대로 둠.
- 가장 큰 이유는 **덮는 행이 적다**는 것. 규칙이 급등락을 반대로 찍은 320행 중 LLM 방향이 있는 행은 뉴스 6, Reddit 10행뿐임.
- 또 하나는 **LLM 방향이 갭보다 약하다**는 것. 둘이 엇갈리면 주가는 대부분 갭 쪽으로 감. 그래서 train 이 게이트를 끄고(off), 방향 가중치 β 를 음수로 고름.
- 데이터 검증은 통과함: 누수 0건, 홀드아웃 0행, 결합 키·달력 일치, 기존 기준 점수 그대로 재현.

## 1. 오늘 전제

- 제출본 v1 = B(민영) `gap_z + ext_range_z` 규칙, fold4 0.515.
- 10/6 분석 결론: 점수는 **급등락 날의 방향**에서 갈림. 크기 정보만으로는 안 오름. 그래서 채민이 LLM(gemini-3.1-flash-lite)으로 뉴스 제목에서 "실적이 예상보다 좋았나/나빴나(surprise)", Reddit 제목에서 "작성자가 상승/하락 의견인가(stance)" 를 뽑음.
- **평가 기간 피처는 우리가 만들어 제출하는 방식**으로 가정함. 교수님 답변 요지: "하던 대로 하면 되고, 실제 test 기간은 우리가 직접 크롤링해야 할 수도 있음".
- 지킨 것: 홀드아웃(대상일 2026-06-01~) 안 봄, LLM API 호출 없음, `src/model.py`·`artifacts/` 안 고침, push 안 함.

### 3.4 신호 미리 보기 (모델 없이 표만 세기)

"수익률 > 0 비율"(상승)과 "급등락(0·4) 비율"을 셈. 전체 평균은 상승 약 52%, 급등락 약 16~20%.

| | 뉴스: 상회>0 | 뉴스: 하회>0 | 뉴스: 둘 다 0 | Reddit: 상승 의견>0 | Reddit: 하락 의견>0 | Reddit: 둘 다 0 |
|---|---|---|---|---|---|---|
| EDA 기간 (target ≤ 02-12) 행 | 297 | 81 | 1,568 | 481 | 189 | 2,983 |
| 상승 비율 | 50.2% | 35.8% | 53.3% | 54.7% | 52.4% | 52.2% |
| 급등락 비율 | 43.4% | 51.9% | 17.7% | 24.1% | 25.9% | 20.6% |
| 평균 수익률 | +0.36% | −1.53% | +0.15% | +0.39% | −0.07% | +0.09% |
| fold4 기간 (target 03-05~05-29) 행 | 44 | 8 | 226 | 91 | 32 | 435 |
| 상승 비율 | 50.0% | 37.5% | 51.8% | 59.3% | 46.9% | 47.6% |
| 급등락 비율 | 52.3% | 50.0% | 24.3% | 23.1% | 25.0% | 28.5% |

읽는 법:
- 뉴스 상회/하회가 있는 날은 급등락이 43~52% 로, 아무것도 없는 날(18~24%)의 2배 이상임 → **크기 신호는 강함**.
- 방향은 하회 쪽만 약간 있음: EDA 기간 하회>0 이면 상승 35.8% (평균 52% 보다 낮음). 상회는 50% 로 동전 던지기 수준.
- Reddit 은 크기 신호가 약함 (24~26% vs 20.6%). 방향도 작음 (상승 의견 54.7% vs 하락 의견 52.4%).

갭과 비교 (방향 ≠ 0 이고 gap_z 가 있는 행):

| | 뉴스 EDA 기간 | 뉴스 fold4 | Reddit EDA 기간 | Reddit fold4 |
|---|---|---|---|---|
| 갭과 부호 같음 | 205/344 = 59.6% | 26/49 = 53.1% | 379/635 = 59.7% | 68/116 = 58.6% |
| 엇갈린 행에서 주가가 LLM 쪽으로 감 | 36/139 = 25.9% | 4/23 = 17.4% | 85/256 = 33.2% | 23/48 = 47.9% |

갭과 LLM 방향이 엇갈리면 대부분 **갭이 맞음** (뉴스 74%). 그래서 "LLM 방향으로 갭을 뒤집는" 방식은 기대하기 어렵고, "엇갈리면 급등락으로 찍지 않는" 게이트(실험 b)가 더 그럴듯함.

### 3.5 폴드별로 실제 쓸 수 있는 표본 (가장 중요한 한계)

val 은 한 폴드에 3,000행(60일 × 50종목).

| 폴드 | 뉴스 방향 있는 행 | 뉴스: 급등락이면서 방향 ≠ 0 | Reddit 방향 있는 행 | Reddit: 급등락이면서 방향 ≠ 0 | 급등락 행 |
|---|---|---|---|---|---|
| fold1 | 249 (8.3%) | 28 | 540 (18.0%) | 18 | 299 |
| fold2 | 291 (9.7%) | 22 | 577 (19.2%) | 24 | 388 |
| fold3 | 314 (10.5%) | 30 | 587 (19.6%) | 33 | 482 |
| fold4 | 276 (9.2%) | **24** | 554 (18.5%) | **26** | 586 |

- 계산 예: fold4 뉴스 276 / 3,000 = 9.2%.
- **점수를 바꿀 수 있는 행(급등락 + 방향 있음)은 fold4 에서 뉴스 24행, Reddit 26행뿐임.** 10/6 분석에서 fold4 무작위 흔들림 1σ 가 0.029 였음. 그러니 몇 행만 바뀌어도 0.01 넘게 오르내릴 수 있음. 그래서 bootstrap 과 가짜 피처를 같이 봄 (§5.3, §5.4).

## 4. 실험 설계 (격자는 오전에 고정, 결과 보기 전)

`scripts/a_llm_news.py` 맨 위 "고정 격자" 블록에 있는 내용임.

### 4.1 피처

| 이름 | 원래 열 | 뜻 |
|---|---|---|
| `news_llm_relevant` | `feature_relevant_share` | 후보 기사 중 대상 기업과 관련된 비율 (크기 후보) |
| `news_llm_above` / `_below` | `feature_surprise_above/below_share` | 관련 기사 중 예상 상회 / 하회 비율 |
| `reddit_llm_direct` | `feature_relevance_direct_ratio` | 선택된 글 중 대상 기업을 직접 말한 비율 (크기 후보) |
| `reddit_llm_bull` / `_bear` | `feature_stance_bullish/bearish_ratio` | 작성자 상승 / 하락 의견 비율 |
| `<출처>_llm_dir` | 위(+) − 아래(−) | 방향 (−1 ~ 1). 하나라도 없으면 결측 |
| `<출처>_llm_surp` | 위(+) + 아래(−) | 방향 있는 기사·글 비율 (크기) |

C 표에 `news_*`·`reddit_*` 열이 이미 있어서 `_llm_` 을 넣어 구분함. 결합은 `symbol + target`.

### 4.2 실험과 격자

| 이름 | 방식 | 격자 (train score 최대로 고름) | 결측일 때 |
|---|---|---|---|
| `llm6_base` | 기준: B 규칙 (`v2_rule_base` 와 같음) | λ {0, .1, .2, .3, .4} | — |
| `llm6_a_rsize_relevant` / `rd4_a_rsize_direct` | a. 급등락 경계 b' = b·exp(−δ·x̃) | δ {−.3, −.2, −.1, 0, .1, .2, .3} | 경계 b 그대로 |
| `llm6_a_rsize_surp` / `rd4_a_rsize_surp` | a. 같은데 x = 위 + 아래 | 같음 | 같음 |
| `llm6_b_gate_dir` / `rd4_b_gate_dir` | b. 방향이 규칙과 반대이고 \|dir\| > τ 인 급등락(0·4)을 낮춤 | {off, 한 칸(0→1, 4→3), 보합으로(→2)} × τ {0, .25, .5} = 7개 | 게이트 없음 |
| `llm6_c_radd_dir` / `rd4_c_radd_dir` | c. s' = s + β·sd(s)·dir | β {−.5, −.25, −.1, 0, .1, .25, .5, 1} | 더하는 항 없음 |
| `llm6_d0_lgb_aggr` | 기준: `lgb_v1_aggr` (B 26개) | k {1, 1.25, 1.5, 2, 2.5, 3} | — |
| `llm6_d_lgb_aggr_news` / `rd4_d_lgb_aggr_reddit` / `llm6rd4_d_lgb_aggr_both` | d. LightGBM + LLM 4개 / 4개 / 8개 | 같음 | LightGBM 이 결측을 직접 나눔 |

- x̃ 는 train 에서 **관측된 행만으로** 평균·표준편차를 구해 표준화함.
- "결측 = 0" 으로 채우지 않은 이유: relevant = 0 은 "기사는 있었는데 관련 없음", 결측은 "후보 기사 없음" 이라 뜻이 다름. a 에서는 0 이 평균보다 낮은 x̃ 가 되고, 결측은 경계를 그대로 둠.
- c 에서는 dir = 0 (상회·하회가 같음) 과 결측의 결과가 같음 (둘 다 더하는 항 0). 뜻도 둘 다 "방향 정보 없음" 이라 그대로 둠.
- Reddit 은 오전에 정한 뉴스 격자를 그대로 씀 (새 격자를 만들지 않음).
- **채택 기준** (팀 합의, 그대로): 같은 계열 기준 대비 fold4 하락 없음 + 4폴드 중 3폴드 상승 + 평균 +0.005. 규칙 계열은 `llm6_base`, LightGBM 계열은 `llm6_d0_lgb_aggr` 와 비교.

### 4.3 추가 분석 (격자와 함께 미리 정함)

| 무엇 | 설정 | 왜 |
|---|---|---|
| 날짜 bootstrap | val 날짜를 다시 뽑아 (실험 − 기준) 차이의 95% 구간, 2,000회, seed 0. fold4 와 4폴드 합친 것 | 차이가 우연 수준인지 |
| 가짜 피처 | b·c (뉴스·Reddit) 4개. 관측 행끼리 dir 값을 섞어 30회 다시 돌림 (결측 위치 그대로) | 진짜 LLM 이 섞은 값보다 나은지 |
| 반대로 찍은 급등락 행 | 기준 규칙이 급등락을 반대로 찍은 행 중 LLM 방향이 정답 쪽인 비율 | 10/6 결론("방향이 문제")과 직접 연결 |
| unseen | 처음 보는 10종목 점수를 따로 | 평가 종목 절반이 처음 보는 종목 |

### 5.2 점수와 채택 판정 (같은 계열 기준 대비 차이)

예: `llm6_c_radd_dir` 의 fold1 차이 = 0.4506 − 0.4475 = +0.0031 (표에는 반올림 전 값으로 +0.0030).

| 실험 | f1 | f2 | f3 | **f4** | 평균 | 오른 폴드 | 채택 |

| a 뉴스 상회+하회 → 경계 | 0 | 0 | +0.0024 | +0.0001 | +0.0006 | 2 | X |
| b 뉴스 방향 게이트 | 0 | 0 | 0 | 0 | 0 | 0 | X (네 폴드 모두 off) |
| c 뉴스 방향 더하기 | +0.0030 | +0.0007 | −0.0026 | +0.0001 | +0.0003 | 3 | X (평균 < +0.005) |

| a Reddit 의견 비율 → 경계 | −0.0024 | 0 | +0.0046 | +0.0003 | +0.0006 | 2 | X |
| b Reddit 방향 게이트 | 0 | 0 | 0 | 0 | 0 | 0 | X (네 폴드 모두 off) |

### 5.3 train 이 고른 값 (모델이 LLM 을 어떻게 썼나)

| 실험 | 폴드별로 고른 값 (f1/f2/f3/f4) | 뜻 |
|---|---|---|
| b 게이트 (뉴스·Reddit) | off / off / off / off | 엇갈리는 급등락을 낮추면 train 점수가 떨어짐 → 안 씀 |
| c 뉴스 방향 더하기 | β = −0.25 / −0.1 / −0.1 / −0.1 | **음수**: LLM 이 "좋다" 고 하면 오히려 아래로 조금 밂 |
| c Reddit 방향 더하기 | β = −0.1 / −0.25 / −0.1 / −0.1 | 마찬가지로 음수 |
| a 뉴스 관련 비율 | δ = 0 / 0 / −0.3 / −0.3 | 음수: 관련 기사 많으면 급등락 경계를 **올림** (10/6 의 크기 정보 결과와 같은 방향) |
| a 뉴스 상회+하회 | δ = 0 / 0 / +0.2 / +0.2 | 양수: 서프라이즈 기사 있으면 급등락으로 쉽게 찍음 (§3.4 의 크기 신호와 맞음) |

β 가 음수인 이유는 §3.4 갭 비교와 같은 그림으로 볼 수 있음. 갭과 LLM 방향이 엇갈리면 주가는 대부분 갭 쪽으로 감 (뉴스 74%). 이미 실적이 갭에 반영된 뒤라, 방향을 더 믿으면 손해인 것으로 보임.

### 5.4 우연인지 확인 1 — 날짜 bootstrap

val 날짜 60일을 중복 허용해서 60번 다시 뽑고, (실험 점수 − 기준 점수) 를 계산함. 이걸 2,000번 반복해서 가운데 95% 범위를 봄. 범위에 0 이 들어 있으면 "날짜 운에 따라 0 일 수도 있다" 는 뜻임.

| 실험 | fold4 95% 범위 | fold4 에서 차이 ≤ 0 인 비율 | 4폴드 합친 95% 범위 |
|---|---|---|---|
| c 뉴스 방향 더하기 | −0.0007 ~ +0.0008 | 34.6% | −0.0014 ~ +0.0013 |
| c Reddit 방향 더하기 | −0.0006 ~ +0.0033 | 11.3% | −0.0012 ~ +0.0017 |
| a Reddit 의견 비율 | −0.0041 ~ +0.0045 | 45.0% | −0.0011 ~ +0.0030 |
| d LightGBM + 뉴스 | −0.0108 ~ +0.0127 | 40.7% | −0.0062 ~ +0.0098 |
| d LightGBM + 둘 다 | −0.0017 ~ +0.0181 | 4.2% | −0.0071 ~ +0.0117 |

- 모든 실험에서 95% 범위가 0 을 포함함.
- "LightGBM + 둘 다" 는 fold4 만 보면 차이 ≤ 0 이 4.2% 로 작음. 그런데 4폴드를 합치면 범위가 −0.0071 ~ +0.0117 로 넓어짐. fold4 만 좋은 것으로 보임.

### 5.5 우연인지 확인 2 — 가짜 피처 30회

LLM 방향 값을 있는 행끼리 무작위로 섞음 (어느 행에 값이 있는지는 그대로). 그리고 같은 실험을 30번 다시 돌림. 진짜 LLM 이 의미가 있다면 섞은 것보다 확실히 높아야 함.

| 실험 | 진짜 fold4 | 가짜 30회 fold4 중앙값 (최대) | 가짜 ≥ 진짜 | 진짜 평균 | 가짜 평균 중앙값 | 가짜 ≥ 진짜 |
|---|---|---|---|---|---|---|
| b 뉴스 게이트 | 0.5154 | 0.5154 (0.5156) | 24/30 | 0.4501 | 0.4501 | 21/30 |
| c 뉴스 방향 더하기 | 0.5155 | 0.5154 (0.5161) | 7/30 | 0.4504 | 0.4499 | 4/30 |
| b Reddit 게이트 | 0.5154 | 0.5154 (0.5154) | 29/30 | 0.4501 | 0.4501 | 26/30 |
| c Reddit 방향 더하기 | 0.5166 | 0.5156 (0.5175) | 6/30 | 0.4503 | 0.4498 | 7/30 |

- 읽는 법: "가짜 ≥ 진짜 6/30" 은 섞은 값으로 돌린 30번 중 6번이 진짜보다 같거나 좋았다는 뜻 (20%).
- 방향 더하기(c)는 가짜보다 조금 낫지만 (평균 4/30 = 13%, 7/30 = 23%), 보통 기준으로 보는 5% 보다 큼. 차이 크기도 0.0005 수준임.
- 게이트(b)는 진짜·가짜 모두 거의 매번 off 를 골라 구분이 안 됨.

### 5.6 반대로 찍은 급등락 행에 LLM 이 있었나

10/6 결론: 벌점의 절반이 "급하락인데 상승 이상으로, 또는 급상승인데 하락 이하로" 찍은 행에서 나옴. 이 행들에서 LLM 이 맞는 방향을 알려 줬다면 고칠 수 있었음.

| | fold1 | fold2 | fold3 | fold4 | 합 |
|---|---|---|---|---|---|
| 기준 규칙이 반대로 찍은 급등락 행 | 54 | 72 | 98 | 96 | 320 |
| 뉴스 LLM 값이 있는 행 | 7 | 7 | 15 | 6 | 35 (10.9%) |
| 그중 방향 ≠ 0 | 2 | 0 | 3 | 1 | **6** |
| 그중 방향이 정답 쪽 | 0 | 0 | 3 | 0 | 3 |
| Reddit LLM 값이 있는 행 | 11 | 16 | 17 | 20 | 64 (20.0%) |
| 그중 방향 ≠ 0 | 2 | 4 | 1 | 3 | **10** |
| 그중 방향이 정답 쪽 | 1 | 3 | 0 | 3 | 7 |

- fold4 의 96행은 10/6 분석 숫자(96행)와 같음.
- **고칠 수 있었던 행이 320행 중 뉴스 6행, Reddit 10행뿐임** (6/320 = 1.9%, 10/320 = 3.1%).
- Reddit 은 10행 중 7행이 정답 쪽이라 방향은 맞는 편임. 하지만 행이 너무 적어 점수를 바꾸지 못함.

## 6. 해석

### 6.1 한 줄 요약 (§0 에 옮김)

- LLM 뉴스·Reddit 피처 11개 실험 중 **채택 기준 통과 0개**. 제출본은 B 규칙 v1 (fold4 0.5154) 그대로 둠.
- 이유는 두 가지임. **① 덮는 행이 적음**: 벌점의 핵심인 "반대로 찍은 급등락" 320행 중 LLM 방향이 있는 행은 뉴스 6, Reddit 10. **② 방향이 갭보다 약함**: 갭과 엇갈리면 주가는 대부분 갭 쪽으로 감. 그래서 train 은 게이트를 끄고, 방향 가중치를 음수로 고름.
- 크기 신호는 있음. 뉴스 서프라이즈가 있는 날은 급등락 비율이 2배 이상임. 하지만 10/6 에 본 대로, 크기 정보만으로는 점수가 거의 안 오름.

### 6.2 비유로 설명하면

갭은 "시험 전날 밤 이미 발표된 성적표" 같은 것임. 장 시작 전에 실적 뉴스가 나오면 시간외 거래에서 이미 값이 움직이고, 그게 갭임. LLM 이 제목에서 읽은 "예상보다 좋았다" 는 같은 성적표를 한 번 더 읽은 것이라 새 정보가 거의 없음. 둘이 엇갈릴 때는 실제 돈이 움직인 갭 쪽이 더 정확했음 (뉴스 74%).

### 6.3 발표·보고서에 쓸 수 있는 것 (정성 평가용)

- "LLM 피처가 안 통했다" 를 근거와 함께 보일 수 있음: 덮는 행 수(§3.5, §5.6), train 이 고른 값(§5.3), bootstrap(§5.4), 가짜 피처(§5.5).
- 누수 검사, 결측 처리, 결합 키 테스트로 "LLM 을 안전하게 붙이는 절차" 를 보여 줄 수 있음 (§3).
- 같은 격자를 결과 보기 전에 고정했고, 뉴스에서 정한 격자를 Reddit 에 그대로 씀 → 검증 점수 보고 고르기를 안 했다는 근거.

## 7. 제출에 넣으려면 (지금은 넣지 않음)

이번에 채택된 게 없어서 `src/model.py`·`artifacts/` 는 바꾸지 않음. 나중에 기간·범위를 늘려 채택되는 게 생기면 필요한 것:

1. 채민 추출 코드를 평가 기간 날짜로 돌릴 수 있게 정리 (노트북 `BA_llm_1차.ipynb` → 스크립트). 입력은 cutoff 앞 제목만.
2. 결과 CSV 를 `artifacts/` 에 넣고 `load_model()` 이 읽게 함. 결합은 `symbol + target`.
3. 그날 피처가 없으면 B 규칙 그대로 가게 함 (이번 실험이 이미 이렇게 동작함).
4. 채민의 `aliases`(기업명 사전)에는 공개 50종목만 있음 (우리 unseen 10개 포함). 평가 때 **새로 나오는 10종목**은 사전에 없음 → 그날 `day.symbols` 로 새 종목 이름을 넣는 절차가 필요함.
