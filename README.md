# 다음 거래일 주가 방향 예측

미국 주식 50종목의 **다음 거래일 종가 방향**을 개장(09:30) 전에 5등급으로 예측합니다. 2026년 2학기 Business Analytics 팀 프로젝트(3인)이고, 데이터와 평가 지표·채점 인터페이스의 정의는 과목에서 주어졌습니다.

최종 제출 모델은 **학습된 상수 5개짜리 고정 규칙 하나**이고, 그중 λ이 0으로 학습돼 실제로 작동하는 건 등급 경계 두 개뿐입니다. 같은 피처로 학습한 XGBoost는 2,000회 bootstrap 전부에서 이 규칙보다 낮았습니다. 성능은 모델을 키워서가 아니라 **예측 시점에 합법적으로 쓸 수 있는 가장 최신 가격을 찾아서** 나왔습니다.

| | |
|---|---|
| 기간·규모 | 2026-09-29 ~ 10-21 (3주), 커밋 105개, 테스트 84개 |
| 데이터 | 50종목 × 522거래일, 일봉·시간봉·뉴스·실적·애널리스트·Reddit + Alpaca 1분봉 |
| 최종 점수 | **홀드아웃 0.6534** (기준선 0.5967, 73거래일·3,650건) |
| 내 역할 | 팀 A — 평가 인프라 전체, 모델 탐색, 누수 검사, 제출본 검증 |
| 스택 | Python 3.11+, uv, pandas/pyarrow, XGBoost, LightGBM, W&B, pytest |

실행 방법은 [docs/RUN.md](docs/RUN.md)에 있습니다.

## 1. 이 문제가 어려운 이유: 지표가 한쪽으로 몰아 찍는 걸 막는다

평가 지표는 단순 정확도가 아니라 **우연 보정 가중 점수**입니다 ([`src/data.py`](src/data.py)).

```
score = 1 − Σ w·O / Σ w·E       O: 실제 혼동행렬, E: 같은 분포에서 무작위로 찍은 기대치
```

- `0`이 기준선입니다. 정보가 없는 예측은 0점입니다.
- **한 클래스만 계속 찍으면 정확히 0점**입니다. 전부 보합이든 전부 급상승이든 같습니다.
- 가중치가 비대칭입니다. 정답이 급등락인 행은 4배, **보합인 행은 0배**, 틀린 거리는 제곱으로 깎입니다.

그래서 "대부분 보합이니 보합만 찍는다"는 안전한 전략이 통하지 않습니다. 실제로 측정하면 이렇습니다.

| 전략 | 점수 | 정확도 |
|---|---:|---:|
| 급등락만 잡고 나머지 보합 | **+0.862** | 0.485 |
| 방향만 맞고 세기는 틀림 | +0.834 | 0.844 |
| 급등락을 정반대로 | −1.818 | 0.329 |

정확도 0.844가 0.485보다 낮은 점수를 받습니다. **드물고 큰 움직임을 맞히는 것**이 이 문제의 전부입니다. 일반적인 quadratic weighted kappa와는 값이 다릅니다.

## 2. 결과

### 갭 가격의 시각을 당길수록 점수가 오른다

모든 수치는 같은 폴드·같은 지표(`src.data.score`)입니다. 홀드아웃은 대상일 2026-06-01~09-14, 73거래일·3,650건이고 1회만 사용했습니다.

| 모델 | 개발 4폴드 | 기준선 대비 | 홀드아웃 | 기준선 대비 |
|---|---:|---:|---:|---:|
| B0 — 시간외 갭 (기준선) | 0.4469 | — | 0.5967 | — |
| 프리마켓 09:15 | 0.4636 | +0.017 | 0.5996 | +0.003 |
| 프리마켓 09:28 | 0.4875 | +0.041 | 0.6381 | +0.041 |
| **프리마켓 09:29 (제출)** | **0.4957** | **+0.049** | **0.6534** | **+0.057** |

09:15는 개발에서 보인 이득이 홀드아웃에서 거의 사라졌고(+0.017 → +0.003), 09:28은 폭이 그대로 유지됐습니다(+0.041 → +0.041). 09:15 가격은 개장까지 15분이 남아 정보가 덜 쌓였다는 해석과 맞습니다.

### 트리 모델은 같은 피처로 이 규칙을 넘지 못했다

아래는 **09:15 기준, 홀드아웃을 열지 않고** 개발 4폴드만으로 한 비교입니다 (대상일 2024-08-14~2026-05-28, 448일).

| 모델 | fold1 | fold2 | fold3 | fold4 | 평균 | 처음 보는 종목 |
|---|---:|---:|---:|---:|---:|---:|
| B0 (기준선) | 0.4344 | 0.4356 | 0.4020 | 0.5154 | 0.4469 | 0.3634 |
| B0 + 프리마켓 09:15 — 규칙 | 0.4696 | 0.4244 | 0.4113 | 0.5492 | **0.4636** | **0.3758** |
| XGBoost, 같은 피처 | 0.4341 | 0.3981 | 0.3812 | 0.5065 | 0.4300 | 0.3448 |
| XGBoost + 프리마켓 피처 | 0.4706 | 0.4077 | 0.3956 | 0.5160 | 0.4475 | 0.3479 |

기준선 대비 bootstrap (5거래일 블록, 2,000회, seed 2026)

| 모델 | 평균 차이 | 95% 구간 | 0 이하 비율 |
|---|---:|---:|---:|
| B0 + 프리마켓 09:15 — 규칙 | **+0.0170** | [−0.0055, +0.0385] | 6.8% |
| XGBoost, 같은 피처 | −0.0179 | [−0.0275, −0.0090] | **100%** |
| XGBoost + 프리마켓 피처 | +0.0003 | [−0.0236, +0.0227] | 48.3% |

XGBoost는 `max_depth=2`, `min_child_weight=100`, `reg_lambda=20`에 갭 방향 단조 제약까지 걸어 규제했는데도 **2,000회 전부에서 규칙보다 낮았습니다**. 프리마켓 피처를 줘도 48.3%, 사실상 동전 던지기입니다. 설정은 [`reports/xgb_premarket/config.json`](reports/xgb_premarket/config.json), 전체 표는 [`REPORT.md`](reports/xgb_premarket/REPORT.md)에 있습니다.

## 3. 핵심 발견: 모델이 아니라 시계를 당겼다

기준선 B0는 **전날 시간외 거래의 마지막 가격**으로 갭을 만듭니다. 예측 시점은 대상일 09:30이므로, 그 사이 프리마켓 시간대(08:00~09:30)의 가격은 쓰지 않고 버리는 셈입니다.

제출 모델은 갭 가격만 **대상일 09:29까지 끝난 마지막 1분봉**으로 바꿉니다. 수식은 그대로입니다.

```
gap_z = ((09:29까지 확정된 가격 / 전일 종가) − 1) / vol20     vol20 = 최근 20거래일 수익률 표준편차
label = gap_z 를 고정 경계 a≈0.0761, b≈0.2511 로 자른 값
```

이 변경만으로 개발 +0.049, 홀드아웃 +0.057이 나왔습니다. **모델 구조는 한 줄도 바뀌지 않았습니다.** 같은 수식, 같은 파라미터 개수, 갭 가격의 시각만 다릅니다.

누수가 아닌지가 핵심이라 따로 검증했습니다. 봉이 **끝난** 시각이 09:29 이하인 봉만 쓰고(마지막은 09:28 시작·09:29 종료), 과목이 준 시간봉의 `known_at` 규칙과 같은 기준입니다. 저장된 **23,771행 전부**를 검사해 09:29 이후에 끝나는 봉이 0건임을 확인했습니다 ([`reports/premarket_submission_check.json`](reports/premarket_submission_check.json)).

곁가지로 하나 더 나왔습니다. 09:28은 방향 적중률이 오히려 기준선보다 **낮습니다** (0.69 → 0.66). 대신 보합으로 답하는 비율이 두 배입니다 (0.076 → 0.15). 최신 가격이 "확신 없는 날을 보합으로 빼는" 쪽으로 작동해 크게 틀릴 날을 줄인 것으로 보이는데, **이건 추정이고 검증하지 않았습니다.**

## 4. 내가 만든 것: 무엇이 통했는지 판정하는 장치

프리마켓 갭 아이디어와 수집 코드는 팀원 B(김민영)의 작업입니다([`work/b/`](work/b/)). 제가 만든 것은 **그 아이디어가 진짜인지 판정할 수 있는 평가 인프라**이고, 같은 장치로 제 후보들을 기각했습니다.

### 검증 설계 ([`lab/folds.json`](lab/folds.json), [`lab/cv.py`](lab/cv.py))

- 확장 학습창 4폴드, 각 검증 60거래일
- 폴드마다 **12거래일 embargo** — 20거래일 롤링 피처가 학습·검증 경계를 넘지 못하게
- **종목 10개를 아예 빼고 학습** (BA, BKNG, CVS, GLW, NFLX, PFE, QCOM, RTX, TMO, WELL) — 40종목으로 맞추고 50종목에 채점해, 종목별 과적합과 일반화를 분리해서 봄
- 홀드아웃은 2026-06-01부터 봉인

### 누수 검사 ([`lab/leak.py`](lab/leak.py), [`tests/test_leak.py`](tests/test_leak.py))

모든 피처가 대상일 09:30 이전 `known_at` 정보만 쓰는지, 날짜를 뒤에 더 붙여도 앞선 행의 피처가 변하지 않는지 검사합니다. 뒤를 보는 피처는 이 검사에서 값이 바뀝니다.

## 6. 한계

정직하게 적어 둘 것들입니다.

- **홀드아웃은 완전히 손대지 않은 검증이 아닙니다.** 09:28과 09:29 중 09:29를 고를 때 홀드아웃 점수를 같은 표에 놓고 봤습니다(09:29가 개발 +0.008, 홀드아웃 +0.015). 09:28까지는 표본 밖 1회 검사였고, 마지막 1분을 고른 결정에는 홀드아웃이 들어갔습니다.
- **모든 모델이 홀드아웃에서 개발보다 높습니다.** 그 기간에 갭이 방향을 잘 맞힌 구간 효과이고, 기준선도 같이 올랐습니다. 0.6534를 일반적인 기대 성능으로 읽으면 안 됩니다.
- 방향 적중률은 기준선보다 낮습니다. 보합 비율로 설명하는 가설은 검증하지 않았습니다.
- 프리마켓 1분봉은 Alpaca 무료 계정의 과거 데이터입니다. 당일 개장 직전 실시간 수집에는 SIP 지연·권한 제약이 있어, 과거 데이터 일괄 평가와 같다고 보장할 수 없습니다.
- 비공개 10월 평가 결과는 아직 받지 못했습니다. 위 숫자는 모두 공개 구간 기록입니다.
